## 0x01
1、需要一台境外的vps服务器，由服务器转发数据。

<font style="color:rgb(0, 0, 0);">2、OpenSSH，</font>本地如果是比较老的Windows就需要OpenSSH支持。<font style="color:rgb(0, 0, 0);">（OpenSSH是安全 Shell (SSH) 工具的开放源代码版本，Linux 及其他非 Windows 系统的管理员使用此类工具跨平台管理远程系统。 OpenSSH 在 2018 年秋季已添加至 Windows，并包含在 Windows 10 和 Windows Server 2019 中。详见</font>[https://www.openssh.com/manual.html](https://www.openssh.com/manual.html)<font style="color:rgb(0, 0, 0);">，这里只是用到ssh.exe）</font>

![](https://image-1253434595.cos.ap-chengdu.myqcloud.com/img/202409241335581.png)

<font style="color:rgb(0, 0, 0);">SSH 基于客户端-服务器体系结构，用户在其中工作的系统是客户端，所管理的远程系统是服务器。 OpenSSH 包含一系列组件和工具，用于提供一种安全且简单的远程系统管理方法，其中包括：</font>

+ <font style="color:rgb(0, 0, 0);">sshd.exe，它是远程所管理的系统上必须运行的 SSH 服务器组件</font>
+ <font style="color:rgb(0, 0, 0);">ssh.exe，它是在用户的本地系统上运行的 SSH 客户端组件</font>
+ <font style="color:rgb(0, 0, 0);">ssh-keygen.exe，为 SSH 生成、管理和转换身份验证密钥</font>
+ <font style="color:rgb(0, 0, 0);">ssh-agent.exe，存储用于公钥身份验证的私钥</font>
+ <font style="color:rgb(0, 0, 0);">ssh-add.exe，将私钥添加到服务器允许的列表中</font>
+ <font style="color:rgb(0, 0, 0);">ssh-keyscan.exe，帮助从许多主机收集公用 SSH 主机密钥</font>
+ <font style="color:rgb(0, 0, 0);">sftp.exe，这是提供安全文件传输协议的服务，通过 SSH 运行</font>
+ <font style="color:rgb(0, 0, 0);">scp.exe 是在 SSH 上运行的文件复制实用工具</font>

## 0x02
+ <font style="color:rgb(0, 0, 0);">本地转发</font>
    - <font style="color:rgb(0, 0, 0);">ssh -L <local port>:<remote host>:<remote port> <SSH hostname></font>
+ <font style="color:rgb(0, 0, 0);">远程转发</font>
    - <font style="color:rgb(0, 0, 0);">反弹</font>
    - <font style="color:rgb(0, 0, 0);">ssh -R <local port>:<remote host>:<remote port> <SSH hostname></font>
+ <font style="color:rgb(0, 0, 0);">动态转发</font>
    - <font style="color:rgb(0, 0, 0);">ssh -D <local port> <SSH Server></font>



<font style="color:rgb(0, 0, 0);">举个栗子</font>

ssh -fNCR :2222:127.0.0.1:22 root@121.123.312.13 -p22

<font style="color:rgb(0, 0, 0);">将本地的ssh-server的22端口转发到远程主机2222端口</font>

## 0x03

监听本地计算机的1080端口，走的socks5。

```powershell
TASKKILL /F /IM ssh.exe
start .\OpenSSH\ssh -f -N -D :1080 root@45.43.37.243 -p 26122
# -N 告诉SSH客户端，这个连接不需要执行任何命令。仅仅做端口转发
# -f 告诉SSH客户端在后台运行
# -D 动态转发 
#    需要使用的本地端口号
#    最后一个参数是我们用来建立隧道的中间机器的IP地址(IP: 123.123.123.123)
```

执行bat脚本后，输入密码就可以了
